# Computational Group Theory with Python 🐍

A computational study of **abelian and non-abelian groups** using Python, developed as an undergraduate project in Mathematics.

## 📖 About the Project

**Computational Group Theory with Python** explores fundamental concepts of group theory and demonstrates how different algebraic structures can be represented and studied computationally using Python.

The project combines mathematical theory with programming to perform operations involving **elements, orders, subgroups, cyclic subgroups, intersections, products, and quotient groups** across several important classes of groups.

The project was submitted as part of the requirements for the **Bachelor of Science in Mathematics** at **The Gandhigram Rural Institute (Deemed to be University)** in April 2024.

## 🎯 Objectives

The main objectives of this project are to:

* Study fundamental concepts of group theory.
* Represent different algebraic groups computationally using Python.
* Compute the order of elements in different groups.
* Generate and analyze subgroups and cyclic subgroups.
* Determine distinct subgroups and subgroups of a given subgroup.
* Perform operations such as intersection and product of subgroups.
* Construct and display quotient groups.
* Explore both abelian and non-abelian groups through programming.

## 📚 Project Contents

The project consists of **seven chapters**.

### Chapter 1: Introduction

This chapter introduces the fundamental concepts required for the computational study of groups, including:

* Groups
* Order of a group
* Order of an element
* Subgroups
* Cyclic groups
* Quotient groups
* Abelian and non-abelian groups

The chapter also introduces Python as the programming language used throughout the project.

### Chapter 2: Group of Integers Modulo `n`

This chapter studies the group of integers modulo `n`, denoted by **ℤₙ**, under addition modulo `n`.

Python programs are provided to:

* Display the elements of ℤₙ
* Compute the order of an element
* Generate a subgroup
* Find distinct subgroups
* Find distinct subgroups of a subgroup
* Find the intersection of two subgroups
* Find the product of two subgroups
* Construct quotient groups
* Construct quotient groups of subgroups

### Chapter 3: Multiplicative Group of Integers Modulo `n`

This chapter focuses on the multiplicative group of integers modulo `n`, denoted by **Uₙ**.

The programs cover:

* Displaying the elements of Uₙ
* Computing the order of an element
* Generating cyclic subgroups
* Finding the number of distinct cyclic subgroups
* Displaying distinct cyclic subgroups
* Finding distinct subgroups of a cyclic subgroup
* Finding intersections of cyclic subgroups
* Finding products of two cyclic subgroups
* Constructing quotient groups
* Constructing quotient groups of cyclic subgroups

### Chapter 4: General Cyclic Group of Order `n`

This chapter considers a general cyclic group

```text
G = <a>
```

of order `n`.

Python programs are provided for:

* Listing the elements of the group
* Computing the order of an element
* Finding subgroups
* Finding distinct subgroups
* Finding distinct subgroups of a given subgroup
* Finding intersections of subgroups
* Finding products of subgroups
* Constructing quotient groups
* Constructing quotient groups of subgroups

### Chapter 5: Dihedral Group

The project next moves into non-abelian groups by studying the **dihedral group** `D₂ₙ`.

The programs demonstrate how to:

* Display the elements of the dihedral group
* Compute the order of an element
* Find subgroups
* Find distinct subgroups
* Find distinct subgroups of a given subgroup

The report defines the dihedral group of order `2n` for `n ≥ 3` and discusses its elements and subgroup structure.

### Chapter 6: Quaternion Group

This chapter studies the **quaternion group** `Q₄ₙ`, another important example of a non-abelian group.

The Python programs cover:

* Displaying group elements
* Computing the order of an element
* Finding subgroups
* Finding distinct subgroups
* Finding distinct subgroups of a given subgroup

The report also describes cyclic, order-4, and quaternion subgroups occurring within `Q₄ₙ`.

### Chapter 7: Quasi-Dihedral Group

The final chapter focuses on the **quasi-dihedral group** `QD₂ᵅ`.

The programs are used to:

* Display group elements
* Compute the order of an element
* Find subgroups
* Find distinct subgroups
* Find distinct subgroups of a given subgroup

The report treats the quasi-dihedral group as a non-abelian group and discusses its cyclic, dihedral, and quaternion subgroup structures.

## ▶️ Running the Programs

Each program is designed to accept values through user input and display the corresponding group-theoretic result.

For example:

```bash
python filename.py
```

The required input depends on the mathematical structure being studied. For example, programs may request the value of `n`, an element of the group, or a generator of a subgroup.

## 🔬 What This Project Demonstrates

This project provides a practical connection between **abstract mathematical theory and programming**.

Instead of studying group properties only through definitions and theorems, the project implements them as Python programs, allowing the structure of different groups and their subgroups to be explored computationally.

The progression from `ℤₙ` and `Uₙ` to cyclic, dihedral, quaternion, and quasi-dihedral groups also provides a computational exploration of both **abelian and non-abelian group structures**.
